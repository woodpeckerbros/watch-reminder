# Wear OS store screenshots

שני סטים מוכנים להעלאה ל-Google Play:

- `he/` — אחד־עשר צילומים מועמדים בעברית; Google Play מאפשר לבחור ולהעלות עד שמונה מהם.
- `en/` — שמונה צילומים באנגלית.

כל קובץ הוא JPEG אטום בגודל 454×454 וביחס 1:1. הצילומים נוצרו באמולטור עם נתוני הדגמה בלבד ואינם מכילים נתונים מהשעון האישי.

שמונה התמונות הראשונות בכל שפה הן הסט המקורי. לסט העברי נוספו שלוש חלופות ממוקמות ידנית: זמני היום ביום רגיל, תזכורת לברכה ויצירת תזכורת חדשה. יש לבחור מתוכן את שמונת הצילומים החזקים ביותר בעת ההעלאה.
