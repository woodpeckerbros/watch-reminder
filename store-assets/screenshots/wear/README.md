# Wear OS store screenshots

שני סטים מוכנים להעלאה ל-Google Play:

- `he/` — שמונה צילומים בעברית.
- `en/` — שמונה צילומים באנגלית.

כל קובץ הוא JPEG אטום בגודל 454×454 וביחס 1:1. הצילומים נוצרו באמולטור עם נתוני הדגמה בלבד ואינם מכילים נתונים מהשעון האישי.

סדר ההעלאה המומלץ הוא סדר המספרים בשמות הקבצים: מסך בית בבוקר, מסך בית בצהריים, איסוף מהגן ב-15:15, תזכורת מנחה לפי 25 דקות לפני צאת הכוכבים, יום נישואין עברי עם מונה 16, זמני שבת, מסך התראה ומסך בית לילי.
